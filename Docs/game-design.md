# Tiny Guardians Game Design

## 한 줄 정의

Tiny Guardians는 귀여운 캐주얼 판타지풍 3D 로컬 2인 협동 쿼터뷰 핵앤슬래쉬 액션 RPG다.

## 핵심 목표

- 커플이 PC 한 대에서 게임패드 2개로 함께 플레이한다.
- 전방 캐릭터와 서포터 캐릭터가 서로 다른 역할로 협동한다.
- 여러 몬스터를 타격하며 스테이지를 클리어한다.
- 스테이지 클리어 후 얻은 자원으로 아이템 또는 스킬을 업그레이드한다.
- 직접 3D 모델링을 하지 않고 기존 에셋을 적극 활용한다.
- 테스트 챕터를 먼저 빌드하고 플레이해본 뒤 본편 스토리와 규모를 결정한다.

## 장르

- 3D 액션 RPG
- 로컬 2인 협동
- 쿼터뷰 핵앤슬래쉬
- 스테이지 클리어형 전투
- 라이트한 성장/업그레이드 구조

## 비주얼 톤

- 귀여운 캐주얼 판타지
- 아기자기하고 깔끔한 3D 그래픽
- 밝은 색감
- 읽기 쉬운 캐릭터와 몬스터 실루엣
- 부담스럽지 않지만 타격감이 느껴지는 이펙트
- 무섭거나 잔인한 표현은 낮게 유지

## 플레이어 캐릭터

### 전방 캐릭터

역할:

- 근접 전투
- 탱킹
- 몬스터를 붙잡아두기
- 위기 상황에서 버티기

성장 방향:

- 체력 증가
- 방어력 증가
- 도발 범위 증가
- 근접 공격력 증가
- 대시/돌진 성능 강화

### 서포터 캐릭터

역할:

- 후방 지원
- 회복
- 보호막
- 버프
- 원거리 보조 공격

성장 방향:

- 회복량 증가
- 보호막 지속시간 증가
- 버프 효과 증가
- 버프 범위 증가
- 원거리 보조 공격 강화
- 자원 획득 보조

중요 원칙:

서포터는 단순히 회복만 하는 캐릭터가 아니라, 전투 결과와 성장 체감에 직접 기여해야 한다.

## 테스트 챕터

테스트 챕터는 본편 스토리 확정 전 실제 빌드와 플레이 테스트를 위한 Vertical Slice다.

목적:

- 게임패드 2개 로컬 협동 검증
- 쿼터뷰 공유 카메라 검증
- 핵앤슬래쉬 전투 템포 검증
- 탱커/서포터 역할 분담 검증
- 스테이지 클리어 후 업그레이드 성취감 검증
- UE5 제작 흐름 검증

## 테스트 챕터: 마법 숲

총 4개 스테이지로 구성한다.

1. Stage 1: 반짝잎 숲길
   - 약한 슬라임과 버섯 몬스터 중심
   - 이동, 기본 공격, 회피, 회복 등 기본 조작과 전투 학습
2. Stage 2: 꽃가루 정원
   - 원거리 몬스터 또는 상태이상 몬스터 추가
   - 서포터의 회복, 보호막, 버프 역할이 중요해지는 구간
3. Stage 3: 덩굴 폐허
   - 근접 몬스터와 원거리 몬스터 혼합
   - 전방 캐릭터가 적을 붙잡고, 서포터가 지원하는 협동 구조 검증
4. Stage 4: 숲의 심장 보스전
   - 큰 나무 정령 또는 타락한 숲 수호자 보스
   - 3개 스테이지에서 얻은 업그레이드가 체감되는 최종 검증 전투

## 보상과 성장

- 각 스테이지 클리어 후 업그레이드를 선택할 수 있다.
- 업그레이드는 아이템 또는 스킬 강화 형태로 제공한다.
- 매 스테이지마다 플레이어가 강해졌다는 성취감을 느껴야 한다.
- 첫 구현에서는 복잡한 장비 파밍보다 명확한 선택형 업그레이드를 우선한다.

## 본편 설계 원칙

본격적인 스토리라인, 월드 구성, 장기 콘텐츠 설계는 마법 숲 테스트 챕터를 직접 빌드하고 플레이해본 뒤 결정한다.
