# Gameplay Systems

## 목표

이 문서는 Tiny Guardians의 핵심 게임플레이 시스템을 정리한다. 현재 단계에서는 테스트 챕터 구현에 필요한 최소 시스템을 우선한다.

## 로컬 2인 플레이

- PC 한 대에서 플레이한다.
- 화면 하나를 공유한다.
- 게임패드 2개로 두 캐릭터를 각각 조작한다.
- 온라인 멀티플레이는 첫 구현 범위에서 제외한다.
- Steam Remote Play Together와 잘 맞는 구조를 염두에 둔다.

## 카메라

- 디아블로식 쿼터뷰 카메라를 사용한다.
- 두 플레이어가 가능한 한 화면 안에 들어오도록 공유 카메라를 사용한다.
- 플레이어 간 거리가 너무 멀어질 경우 줌아웃 또는 거리 제한이 필요할 수 있다.
- 첫 구현에서는 화면 분할을 사용하지 않는다.

## 기본 조작

공통:

- 이동
- 회피 또는 대시
- 기본 공격
- 피격
- 체력
- 사망과 부활 또는 재시작

전방 캐릭터:

- 근접 기본 공격
- 돌진 또는 대시 공격
- 도발 또는 방어
- 넓은 베기

서포터 캐릭터:

- 원거리 기본 공격
- 회복
- 보호막
- 공격력 버프 또는 적 둔화

## 전투

- 다수의 몬스터를 상대하는 핵앤슬래쉬 전투를 지향한다.
- 첫 테스트 챕터에서는 몬스터 2~3종과 보스 1종을 목표로 한다.
- 타격감은 애니메이션, 이펙트, 사운드, 피격 반응을 함께 사용해 만든다.
- 첫 구현에서는 복잡한 콤보보다 입력 반응성과 가독성을 우선한다.

## 몬스터

초기 후보:

- 슬라임: 느린 근접 몬스터
- 버섯 몬스터: 근접 또는 독/꽃가루 상태이상
- 꽃 정령/씨앗 몬스터: 원거리 공격
- 숲 수호자 보스: 큰 나무 정령 또는 타락한 숲 수호자

## 스테이지 진행

- 테스트 챕터는 3개 몬스터 웨이브 스테이지와 1개 보스 스테이지로 구성한다.
- 각 스테이지를 클리어하면 보상/업그레이드 선택 화면으로 이동한다.
- 업그레이드 선택 후 다음 스테이지로 진입한다.

기본 흐름:

1. 스테이지 시작
2. 몬스터 등장
3. 두 플레이어가 협동 전투
4. 모든 몬스터 처치
5. 보상 자원 지급
6. 업그레이드 선택
7. 다음 스테이지 진입

## 업그레이드

첫 구현 목표:

- 스테이지 클리어마다 업그레이드 선택 제공
- 캐릭터별 업그레이드 최소 3종 이상
- 공격/방어/지원이 모두 체감되도록 설계

전방 캐릭터 업그레이드 예시:

- 공격력 증가
- 최대 체력 증가
- 도발 범위 증가
- 대시 쿨타임 감소

서포터 캐릭터 업그레이드 예시:

- 회복량 증가
- 보호막 지속시간 증가
- 버프 효과 증가
- 원거리 공격 강화

## UI

테스트 챕터 최소 UI:

- 플레이어별 체력 표시
- 스테이지 진행 상태
- 클리어 후 업그레이드 선택 UI
- 시작 메뉴
- 종료
- 최소 옵션

## 미정

- Blueprint 중심 또는 C++ 혼합 비율
- 정확한 입력 매핑
- 캐릭터별 최종 스킬 구성
- 자원 이름과 경제 구조
- 저장/로드 범위
- 보스 패턴
