# Decisions

이 문서는 Tiny Guardians의 중요한 결정과 이유를 기록한다.

## 2026-09-02: Unreal Engine 5 사용 확정

결정:

- Tiny Guardians는 Unreal Engine 5로 개발한다.

이유:

- 고품질 3D 표현을 빠르게 검증하기 좋다.
- Lumen, Nanite, Niagara, Sequencer 등 UE5 기능을 활용할 수 있다.
- Fab/Marketplace의 3D 에셋 생태계를 활용하기 좋다.
- Blueprint와 C++를 혼합할 수 있다.
- Windows 빌드와 Steam 출시를 목표로 삼기 적합하다.

남은 사항:

- 정확한 UE5 버전은 아직 확정하지 않았다.

## 2026-09-02: 게임명과 프로젝트명 확정

결정:

- 게임 이름은 Tiny Guardians로 한다.
- UE 프로젝트명과 폴더명은 `TinyGuardians`를 사용한다.

이유:

- 귀여운 판타지풍 2인 협동 게임의 방향과 잘 맞는다.
- 짧고 기억하기 쉽다.
- UE 프로젝트명으로 사용하기에 공백 없는 `TinyGuardians`가 적합하다.

## 2026-09-02: 로컬 2인 협동으로 시작

결정:

- PC 한 대와 화면 하나에서 게임패드 2개로 조작하는 로컬 2인 협동으로 시작한다.

이유:

- 첫 프로젝트에서 온라인 멀티플레이보다 구현 난도가 낮다.
- 커플이 한 공간에서 함께 플레이하는 경험과 잘 맞다.
- Steam Remote Play Together와도 궁합이 좋다.

## 2026-09-02: 쿼터뷰 핵앤슬래쉬 액션 RPG 방향

결정:

- 디아블로식 쿼터뷰 시점의 핵앤슬래쉬 액션 RPG를 지향한다.

이유:

- 실시간 조작과 타격감을 느끼기 좋다.
- 화면 하나에서 두 캐릭터를 함께 보여주기 좋다.
- 스테이지 클리어, 자원 획득, 업그레이드 성장 루프와 잘 맞다.

## 2026-09-02: 테스트 챕터 우선 제작

결정:

- 본편 스토리와 전체 월드 설계 전에 마법 숲 테스트 챕터를 먼저 만든다.

이유:

- 실제 빌드와 플레이 테스트를 통해 조작감, 전투 템포, 성장 성취감, 협동 재미를 검증해야 한다.
- 첫 작품에서 전체 규모를 너무 빨리 키우는 위험을 줄인다.

테스트 챕터 구성:

- Stage 1: 반짝잎 숲길
- Stage 2: 꽃가루 정원
- Stage 3: 덩굴 폐허
- Stage 4: 숲의 심장 보스전
