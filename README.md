# Tiny Guardians

Tiny Guardians는 Steam 출시를 목표로 준비 중인 귀여운 캐주얼 판타지풍 3D 로컬 2인 협동 액션 RPG 프로젝트다.

## 현재 상태

- 단계: 사전 기획 및 개발환경 준비
- 엔진: Unreal Engine 5 확정, 정확한 UE5 버전은 미정
- 프로젝트명: `TinyGuardians`
- 현재 목표: UE5 프로젝트 생성 전 문서 구조와 테스트 챕터 기획 정리

## 게임 방향

- PC 한 대와 화면 하나에서 게임패드 2개로 플레이
- 디아블로식 쿼터뷰 핵앤슬래쉬 전투
- 전방 근접/탱킹 캐릭터와 후방 지원/회복/버프 캐릭터의 2인 협동
- 스테이지 클리어 후 자원, 아이템, 스킬 업그레이드로 성장
- 기존 Fab/Marketplace 에셋을 활용하고 직접 3D 모델링은 최소화
